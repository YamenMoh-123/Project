User Account Management

Administrators can manage registered user accounts through the User Management section.

Available actions include:

  • Searching users by name
  • Sorting users by account type, status...
  • Disabling user accounts
  • Granting admin to user accounts
  • Deleting accounts

Disabled accounts cannot login until the account has been re enabled

Managing Reviews

Administrators can review user comments

Reviews can be filtered and organized by:

  • User
  • Book
  • Star rating

Review Moderation

Administrators can delete reviews if they are inappropriate by clicking the delete button next to a review

Website Themes

Admins can select a website theme from the settings to change the color and style of the website

Available theme options include:

  • Classic library theme
  • Dark theme
  • Modern theme

Layout Settings

Admins can control how books appear on the books page.

The layout setting changes the number of books displayed per row.

  • Three books per row
  • Four books per row
  • Five books per row
