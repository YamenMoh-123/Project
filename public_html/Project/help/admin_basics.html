Administrator Access

Admins have access to additional management tools that are unavailable to regular users.

After logging into an admin account, the Admin Dashboard can be accessed through the navigation menu.

Admin Dashboard Overview

The Admin Dashboard provides access to the main management features

Available sections include:

  • Book Management
  • User Management
  • Review Management
  • Website Settings
  • Website Status Monitoring

Managing Books

Administrators can manage the complete book list.

Book management features include:

  • Adding new books
  • Editing existing book information
  • Deleting books

Adding New Books

To add a new book, administrators complete the book creation form.

Required information includes:

  • Book title
  • Author
  • Genre
  • Number of pages
  • Publication year
  • Description
  • Book cover image

Editing and Removing Books

Admins can update book information

Existing records can be edited to correct information, update images, or modify descriptions.

Books that are no longer needed can also be removed from the list.

Website Status Monitoring

The dashboard includes a status monitoring section for the status of the website

Administrators can view information such as

  • PHP status
  • Database connection status
  • Website metadata (# of reviews, users, books)
