About Book Archive

Book Archive is an online book catalogue website that allows users to search available books, filter by titles and authors, view detailed book information, rate books, write reviews, and save favourite books.

Registered users have access to additional features including personal favourites and reviews. Administrators have access to management tools for books, users, reviews, and website customization.

Getting Started

If you are a new user you can begin by creating an account. After registering, users gain access to more features
