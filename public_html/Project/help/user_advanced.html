Searching for Books

TITLE provides a search option that allows users to filter books

Users can search using:

  • Book title
  • Author name

Advanced Search Filters

Users can search in detail refine using additional filters.

  • Genre selection
  • Minimum rating
  • Sorting options

Writing Reviews

Logged in users can leave reviews on books.

A review contains:

  • Star rating from 1 to 5
  • Written comments

Editing Reviews

If a user has already submitted a review, the review section will provide an option to edit their existing review.

Managing Favourite Books

Favourite books allow users to create a personal list of books they want to save.

Users can:

  • Add books to favourites
  • Remove books from favourites
  • View their saved favourites list
