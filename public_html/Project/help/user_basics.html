Creating an Account

To access features such as favourites and reviews, users must first create an account.

  1. Open the registration page.
  2. Enter your name, email address, and password.
  3. Confirm your password.
  4. Submit the registration form.
  5. Log in using your new account.

Creating an account allows users to save their favourites and reviews.

Logging In

Existing users can log in using their email address and password.

After logging in, users gain access to additional features including:

  • Saving favourite books
  • Writing book reviews

Browsing Books

The Book Catalogue displays all available books. Each book card provides basic information including:

  • Book cover image
  • Title
  • Author
  • Genre
  • Number of pages
  • Average user rating

Selecting "View Details" on any book shows the the full description and user reviews.

Adding Favourite Books

Logged in users can save books by selecting the favourite button on a book card.

Favourited books can be accessed from the Favorites section in the navigation menu.
